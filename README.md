# Сайт барбершопа «Лезвие»

Одностраничный сайт с онлайн-записью. В паре с ним работает Telegram-бот для записи.

## Что на сайте

- Адаптивная вёрстка: телефон, планшет, компьютер
- Прайс с длительностью услуг, из прайса можно сразу перейти к записи
- Карточки мастеров с кнопкой «Записаться к мастеру»
- Онлайн-запись: услуга, мастер, дата на 14 дней вперёд, свободное время, маска телефона, проверка полей, окно подтверждения
- Индикатор «Открыто сейчас» по реальному времени
- Отзывы, частые вопросы, контакты, ссылка на Яндекс Карты и Telegram-бота

## Стек

HTML, CSS, JavaScript без библиотек. Один файл `index.html`, открывается в любом браузере.

## Настройка

В начале блока `<script>` в `index.html`:

- `TG_BOT` — имя Telegram-бота без @
- `SERVICES` — услуги, цены и длительность
- `MASTERS` — мастера
- `OPEN_H`, `CLOSE_H` — часы работы
